Todom

A stupidly simple todo list.

Every task has a due date, active tasks sort soonest-first, and completing a task records the date. Nothing else.

View on GitHub Changelog

What it is

Todom is a small, dependency-free todo list you run yourself. A tiny Node/Express backend stores tasks server-side in a single JSON file, so every device that opens the page sees the same list.

It installs as a PWA, works offline, and follows your system's dark or light preference. There are no accounts, no tracking, and no external services.

Run it

docker pull ghcr.io/lightmorphic/todom:latest
sudo mkdir -p /opt/todom
docker run -d -p 4080:3000 \
  -v /opt/todom:/data \
  ghcr.io/lightmorphic/todom:latest

Then open http://localhost:4080. Prefer Compose or building from source? See the README.

Features

  • Clean, minimal interface
  • Dark and light mode
  • Due date on every task, sorted nearest-first
  • Colour-coded urgency
  • Completion dates recorded automatically
  • Import and export as JSON
  • Installable PWA, works offline
  • Same task list on every device
